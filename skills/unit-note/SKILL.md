# 단원 정리 (노션용 .md)

첨부된 자료(슬라이드 이미지, 붙여넣은 글 등)를 바탕으로 **단원 정리 노트**를 만든다.
단원명은 사용자가 말한 이름을 쓴다. 말하지 않았으면 자료 내용에서 짧은 단원명을 정해 사용하고, 정한 이름을 답변에 밝힌다.

## 1. 결과 파일

파일명은 `<단원명>_정리.md` (공백 대신 `_`). 노션 "가져오기 → Text & Markdown" 으로 바로 가져올 수 있어야 한다.
실행 환경에 따라 저장 방식이 다르다.

**A. 사용자 PC의 파일에 쓸 수 있는 환경 (Claude Code 등)**
- 폴더: 현재 사용자 홈의 Downloads 폴더 아래 `<단원명>_정리\` (예: `C:\Users\<사용자>\Downloads\<단원명>_정리\`, 없으면 만든다)
- **파일이 이미 있으면 새로 쓰지 말고 이어서 추가**한다.

**B. 채팅 환경 (Claude Desktop 채팅, claude.ai)**
- 내려받을 수 있는 **.md 파일**로 만들어 제공한다. 파일을 만들 수 없으면 전체 내용을 답변으로 출력한다.
- 같은 대화에서 "이 파트도 추가 정리" 요청이 오면, 앞서 만든 파일에 이어서 추가한 **전체 파일**을 다시 제공한다.
- 사용자가 이전에 만든 .md 파일을 첨부하면 그 파일을 기준으로 이어서 추가한다.

이어서 추가할 때는 기존 목차 흐름에 맞는 위치에 새 장/절을 넣고, 겹치는 내용은 합쳐서 하나로 정리한다.

## 2. 서식 (노션)

- 맨 위: `# 이모지 단원명` + 한 줄 요약 콜아웃
- 콜아웃: `<aside>` 블록 (첫 줄 이모지 + **굵은 제목**, 닫기 전 빈 줄)
- 표, 코드 블록(언어 지정), 인용(`>`), 구분선(`---`)을 적극 사용
- 장 번호를 붙인 `##`, 절 번호를 붙인 `###` 로 구성 (예: `## 6. Advice의 타입`, `### 6-1. @Before`)
- 문서 끝: `## 📌 핵심 정리` 에 체크박스(`- [ ]`) 체크리스트 + 출처

## 3. 내용

- 자료 내용은 **빠짐없이** 옮긴다. 슬라이드의 표·annotation 정의·코드는 그대로 살린다.
- 너무 간결한 내용은 이해하기 쉽게 **보충 설명**한다 (왜 필요한지, 비유, 헷갈리는 개념 비교).
- 이해를 돕는 **예시 코드**를 추가해도 된다. 추가한 예시는 자료 코드와 구분되게 "예시"라고 표시한다.
- 실습(TODO) 코드는 **코드 → 코드 해설 → 실행 결과(예시)** 순서로 정리한다. 값이 바뀌는 코드는 단계별로 따라가는 설명을 넣는다.
- 슬라이드의 말풍선 대사는 `> 🧑‍💻 "..."` 인용으로 살려 흐름을 보여준다.
- 자료의 **오타·코드 오류·버전 차이**(예: 의존성 이름, 반환 타입 불일치, 실습 간 충돌)를 발견하면 바로잡고 해당 위치에 `> ⚠️` 경고로 표시한다. 확실하지 않으면 단정하지 않는다.

## 4. 그림 (Mermaid)

그림이 필요한 곳은 Mermaid 코드 블록으로 그리고, **자료의 그림과 최대한 비슷하게** 그린다.

- 시퀀스 그림은 `sequenceDiagram` 으로, 자료와 **같은 참여자 이름·순서**(예: 클라이언트 → 프록시 → Advice → 타겟), 같은 화살표 라벨을 쓴다. 정상/예외 분기는 `alt ... else ... end` 로 나눈다.
- 구조·흐름 그림은 `flowchart` 로 그리고, 자료의 색은 `style 노드 fill:#색,stroke:#색,color:#000` 로 맞춘다.

**노션에서 깨지지 않게 지킬 것**

- `classDiagram` 은 쓰지 않는다 (특수문자 클래스명에서 렌더링 실패). 대신 `flowchart` 를 쓴다.
- 노드 라벨에 `$ : ( ) { } [ ] < > ;` 같은 특수문자가 있으면 라벨 전체를 `"..."` 로 감싼다.
- 라벨 안에 큰따옴표가 필요하면 작은따옴표로 바꾼다. `&quot;` 같은 HTML 엔티티는 쓰지 않는다.
- `alt` 블록 안에서는 활성화 표시(`+`/`-`)를 쓰지 않는다.
- 줄바꿈은 `<br/>` 를 쓴다.

## 5. 마무리 답변

파일을 저장(또는 제공)한 뒤 답변에 다음을 짧게 정리한다.

- 저장 경로 (A 환경일 때 전체 경로)
- 이번에 추가/변경한 장·절 목록
- 바로잡은 자료 오류 (있으면)
- 노션 가져오기 방법 한 줄: 설정 → 가져오기 → Text & Markdown
- (B 환경) 다음 파트를 다른 대화에서 이어 정리하려면 이 .md 파일을 함께 첨부하라는 안내
